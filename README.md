# AGAR MAIN KING HOTA 👑

A browser-based campaign prototype within the **ASOKA TO BOO-DA** macro arc.

## Run
Open `index.html` in a modern browser, or enable GitHub Pages for this repository.

## Prototype features
- Native image file picker and local image preview
- Photo remains in the browser; no server upload
- King character, co-star count, and idea prompt
- 60-second client-side challenge timer
- Poster generation in-browser with download and share options

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main**, folder **/(root)**, then **Save**.
5. Wait for GitHub Pages to publish; the site URL will appear in the Pages section.

This is a front-end demo. Timer, poster creation, and crown status are local and do not constitute a verified contest or prize entry. No backend, account system, matchmaking, or shared leaderboard is included yet.
