## AI security

Never expose an AI provider API key in browser JavaScript.

Intended architecture:

Browser → Cloudflare Worker/API → AI provider

Before public launch, verify the Worker route, provider secret, CORS policy, abuse controls, rate limits, consent/privacy language and billing controls.
